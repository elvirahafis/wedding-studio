# 💍 WeddingStudio CMS — Undangan Pernikahan Digital Eksklusif

Website Undangan Pernikahan Digital & Visual Theme Customizer (CMS) siap jual di berbagai platform digital seperti **Lynk.id, Gumroad, Mayar, Shopee, ThemeForest, Fastwork, atau jasa freelance wedding organizer**.

---

## 🌟 Fitur Utama

### 1. 📱 Website Undangan Single-Page Interaktif (`index.html`)
- **Cover Amplop Mewah (Envelope Curtain)**: Animasi pembuka amplop dengan stempel wax seal, inisial monogram, nama tamu undangan terpersonalisasi, dan tombol *"Buka Undangan"*.
- **Pemutar Musik Latar (Floating Vinyl Disc)**: Animasi piringan hitam berputar dengan tombol play/pause otomatis saat undangan dibuka.
- **Hitung Mundur (Countdown Timer)**: Real-time countdown bento grid (Hari, Jam, Menit, Detik) menuju waktu akad/resepsi.
- **Profil Pasangan (The Couple)**: Kartu foto haute couture editorial untuk Mempelai Pria & Mempelai Wanita lengkap dengan nama gelar, orang tua, profesi, dan tautan Instagram.
- **Kutipan Suci / Ayat**: Dilengkapi Surah Ar-Rum 21 dengan teks Arab dan terjemahan puitis.
- **Timeline Kisah Cinta (Our Love Story)**: Garis waktu interaktif vertikal menceritakan perjalanan cinta dari awal jumpa hingga lamaran.
- **Galeri Foto (Moments of Grace)**: Bento grid asimetris dengan modal Lightbox pembesar foto beresolusi tinggi.
- **Rangkaian Acara (Akad & Resepsi)**: Jadwal lengkap, tata busana (dresscode swatches), tombol 1-klik simpan ke **Google Calendar**, dan petunjuk arah.
- **Peta Lokasi & Panduan Etika**: Integrasi Google Maps, info antar jemput shuttle, serta 4 kartu etika tamu undangan (*Unplugged ceremony, tepat waktu, kesehatan, kenyamanan*).
- **Konfirmasi Kehadiran (RSVP)**: Formulir konfirmasi kehadiran (Hadir / Tidak), jumlah tamu, preferensi makanan, langsung tersimpan ke sistem.
- **Tanda Kasih & Amplop Digital**:
  - Kartu rekening Bank BCA, Mandiri, dll dengan tombol 1-klik **Salin Nomor Rekening** + notifikasi Toast.
  - Modal **QRIS Amplop Digital** (GoPay, OVO, Dana, ShopeePay, Mobile Banking).
  - Drawer alamat pengiriman kado fisik lengkap dengan no kontak penerima.
- **Buku Tamu / Doa & Ucapan**: Live guestbook feed dengan fitur like/hati, waktu pengiriman, dan avatar inisial.
- **Personalisasi Nama Tamu via URL**: Mengubah nama tamu secara instan lewat link:
  `index.html?to=Bapak+Joko+Widodo+dan+Keluarga`

  - **Download Config (JSON)**: Simpan konfigurasi tema per klien.
  - **Upload Config (JSON)**: Muat kembali data klien lama kapan saja.
  - **Unduh Jadi (HTML)**: Ekspor website undangan mandiri siap upload ke hosting tanpa butuh database/server!

## 🚀 Cara Menjalankan Secara Lokal

Cukup buka file di browser atau jalankan server lokal:

```bash
# Menggunakan Python (port 3000):
python -m http.server 3000

# Atau menggunakan Node.js npx serve:
npx -y serve .
```

- Buka `http://localhost:3000/admin.html` untuk masuk ke CMS Studio.
- Buka `http://localhost:3000/index.html` untuk melihat tampilan undangan penuh.

## 💰 Panduan Menjual di Platform Digital

### Model 1: Jual Jasa Pembuatan Undangan (High Margin)
1. Klien mengirim data (nama pengantin, tanggal, lokasi, foto, rekening).
2. Anda buka `admin.html`, masukkan data klien, dan pilih tema warna yang cocok dalam 5 menit.
3. Gunakan **Generator Link Tamu** untuk membuat daftar link WhatsApp klien.
4. Klik tombol **"Unduh Jadi (HTML)"** dan deploy ke hosting gratis seperti **Vercel, Netlify, atau GitHub Pages** dengan domain custom klien (contoh: `arya-maya.com`).

### Model 2: Jual Template Digital (Passive Income)
1. Upload paket template ini ke platform seperti **Lynk.id, Mayar, Shopee, atau Gumroad**.
2. Pembeli mendapatkan file zip yang berisi `index.html`, `admin.html`, `css/`, dan `js/`.
3. Pembeli cukup membuka `admin.html` di laptop/HP mereka, mengedit sendiri sesuka hati, dan menekan tombol download!
